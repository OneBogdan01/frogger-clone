# Froggy Splat

A Frogger clone made in Godot, and my third entry for the [20 Games Challenge](https://20_games_challenge.gitlab.io/).

## About
The challenge this time was making the sprites and music! The code is here as well, I feel that I am finally getting the hang of it in Godot.

## Features

- intro menu, game over screen and a credits menu; all is a modified version of [Maaack's Game Template
](https://store.godotengine.org/asset/maaack/maaacks-game-template/)
- The mechanics of Frogger are not that complicated..., but they are in this project!
- A pipeline for making 3D assets into 2D pixel art sprites
